| 컴포넌트 | 역할 | 주요 기술 |
|----------|------|-----------|

| **Celery + Redis** | 비동기 작업 큐 (영상 변환, AI 호출) | Celery, Redis |
| **Airflow** | 워크플로우 스케줄링 & 의존성 관리 | Apache Airflow |

## 3. 구현 방안

1. **작업 요청 수신**  
   * `/video/submit` 엔드포인트에서 JSON payload(영상 파일 URL, 스크립트 옵션) 수신.  
   * Pydantic 모델로 유효성 검사 후 Celery 작업 큐에 등록.

2. **비동기 워크플로우**  
   * Airflow DAG에서 `video_pipeline` 태스크 정의.  
   * 의존성: `transcribe`, `trim`, `caption`, `encode`, `thumbnail`.  
   * 각 태스크는 Docker 컨테이너에서 실행, 로그를 Loki에 전송.

3. **오류 처리**  
   * Celery에서 `retry` 로직 (max 3회).  
   * Airflow에서는 태스크 실패 시 Slack 알림.  
   * 오류율을 Prometheus metric(`video_pipeline_errors_total`) 로 전송.

4. **생산성 측정**  
   * `video_pipeline_duration_seconds` metric를 Prometheus에 전송.  
   * Grafana 대시보드에서 `average_duration`과 목표값(378s) 비교.

5. **자동화 스크립트**  
   * `scripts/ffmpeg_trim.py` → 자동 트림.  
   * `scripts/caption_generator.py` → Whisper + GPT‑4 캡션 생성.  
   * `scripts/thumbnail_gen.py` → Pillow 로 썸네일.

"""
hook_library.py

이 모듈은 썸네일과 자막 생성에 필요한 외부 API와의 연동을 담당합니다.
현재는 초기 구조만 제공하며, 실제 엔드포인트와 인증 로직은 나중에 채워집니다.

- Thumbnail API : POST /api/v1/thumbnail
- Subtitle API : POST /api/v1/subtitle

각 함수는 요청 파라미터를 받아서 API 호출 결과를 반환합니다.
"""

import os
import json
from typing import Dict, Any

# 환경 변수 로드 (API 키 등)
THUMBNAIL_API_URL = os.getenv("THUMBNAIL_API_URL", "https://api.example.com/v1/thumbnail")
SUBTITLE_API_URL = os.getenv("SUBTITLE_API_URL", "https://api.example.com/v1/subtitle")
API_KEY = os.getenv("API_KEY")  # 공통 키

def _post_request(url: str, payload: Dict[str, Any]) -> Dict[str, Any]:
    """
    내부 헬퍼: POST 요청 수행
    [근거: 코드 베이스에서 공통 API 호출 패턴 참고]
    """
    import requests
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}"
    }
    response = requests.post(url, headers=headers, json=payload)
    response.raise_for_status()
    return response.json()

def generate_thumbnail(video_path: str, output_dir: str = "./thumbs") -> Dict[str, Any]:
    """
    썸네일 생성 API 호출
    :param video_path: 입력 비디오 파일 경로
    :param output_dir: 썸네일 저장 디렉터리 (생성 가능)
    """
    payload = {
        "video_path": video_path,
        "output_dir": output_dir
    }
    return _post_request(THUMBNAIL_API_URL, payload)

def transcribe_subtitle(video_path: str, language: str = "ko") -> Dict[str, Any]:
    """
    자막 생성 API 호출
    :param video_path: 입력 비디오 파일 경로
    :param language: 타깃 언어 코드
    """
    payload = {
        "video_path": video_path,
        "language": language
    }
    return _post_request(SUBTITLE_API_URL, payload)

if __name__ == "__main__":
    # 예시 실행

    print("Thumbnail 생성 시도:", generate_thumbnail(video))
    print("Subtitle 생성 시도:", transcribe_subtitle(video, "ko"))

### 2. 컴포넌트화 및 상태 관리 (Componentization & State)
썸네일은 여러 개의 독립적인 '컴포넌트'가 조합되어 완성됩니다. 각 컴포넌트는 입력 데이터(Props)에 따라 출력이 달라져야 합니다.

*   **[Risk Component]:** `potential_loss` 값이 0이 아닐 경우, 이 컴포넌트가 강제적으로 삽입되며 배경의 **위험 강조 효과 (빨간색 하이라이트)**와 함께 노출되어야 합니다.
    *   *Logic:* IF (`Potential Loss > 0`) THEN Render(Risk Component); ELSE Hide(Risk Component).
*   **[Solution Component]:** JKstory의 핵심 기능을 나타내는 아이콘과 설명 블록입니다. 공포감이 최고조에 달했을 때, 이 컴포넌트가 **시각적 방어막처럼** 전면에 등장해야 합니다. [근거: Self-RAG, Phase 2]

*   **구조:** **AI 리스크 예측 엔진, Source Grounding 시스템 등 3가지 핵심 기능 아이콘 배치.** (아이콘은 `color-solution-win`으로 강조)
*   **자동화 변수 주입:** 각 아이콘 아래의 상세 설명에는 해당 기술이 어떤 종류의 '리스크'를 막는지 명시하는 **Placeholder Text**가 자동 삽입되어야 합니다.

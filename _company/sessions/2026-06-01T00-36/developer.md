# 💻 코다리 — 썸네일 자동화 파이프라인(E2E Test)의 최종 통합 검증을 완료하고, 디자인 시스템 V2.0 사양과의 완벽한 일치 여부를 확인하여 자동화 프로세스를 안정화하라.

💻 코다리: 오늘 업무 우선순위 및 에이전트 배분

1️⃣ **썸네일 자동화 파이프라인(E2E Test) 최종 통합 검증**  
   - **담당자:** 💻 코다리 (개발)  
   - **목표:** `thumbnail_data_schema_v1.json`과 Figma 프로토타입 사양을 기반으로 자동화 스크립트가 디자인 시스템 V2.0과 100% 일치하도록 검증하고, E2E 테스트를 통과시켜 프로세스 안정화.  
   - **핵심 단계:**  
     1. 스키마와 디자인 사양 로드 → 타입검증 (Pydantic)  
     2. 자동화 스크립트 실행 → 이미지/메타데이터 생성  
     3. 생성 결과를 사양과 비교 → 레이어, 색상 코드(`#C94A1B`, `#007BFF`) 일치 여부 확인  
     4. 통합 테스트 결과를 `e2e_report.json`에 저장 → CI 파이프라인 연동  

2️⃣ **콘텐츠 제작용 인스타그램 릴스/피드 레이아웃 가이드라인 최종 확정**  
   - **담당자:** 📷 Instagram (디자인)  
   - **목표:** 디자인 시스템 V2.0에 맞춘 인스타그램용 컴포넌트 사양 완성, 레이아웃 가이드라인(릴스 비율 9:16 등) 정리.  
   - **핵심 단계:**  
     - Figma 프로토타입에서 레이어 구조 추출 → JSON 사양화  
     - 비율, 텍스트 스타일, 색상 매핑 검증  
     - 최종 사양을 `instagram_layout_spec.yaml`에 저장  

3️⃣ **유튜브 영상 주제 및 SEO 키워드 최종 선정**  
   - **담당자:** 📺 레오 (콘텐츠 기획)  
   - **목표:** 10편 영상 주제와 SEO 키워드, 스토리텔링 패턴(추억 회고/일상 위로/기술 체험) 최종 확정.  
   - **핵심 단계:**  
     - 기존 영상 데이터 분석 결과 반영 → `youtube_topic_plan.xlsx` 작성  
     - SEO 키워드(검색 의도 기반) 및 스토리텔링 패턴 매핑  
     - 최종 주제 리스트를 `youtube_final_plan.md`에 기록

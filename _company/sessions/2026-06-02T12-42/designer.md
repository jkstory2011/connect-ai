**작성 목적:** 코다리 에이전트가 개발한 자동화 모듈(`generate_thumbnail`)의 결과물이, Designer가 확정한 브랜드 디자인 시스템(V3.0 사양)과 100% 일치함을 증명하고, 향후 콘텐츠 제작 시 모든 팀원 및 외부 협력자가 따라야 할 표준 운영 절차(SOP)를 확립합니다.

**적용 범위:** YouTube 썸네일 (최종 해상도: 1280x720px).
**검증 기준:** 브랜드 일관성, 정보 계층 구조, 감정적 전환 유도 (Pain $\to$ Solution).

### I. 디자인 시스템 매개변수 재확인 (The Design Tokens) [근거: Self-RAG, Designer Memory]

자동화 모듈이 반드시 준수해야 하는 핵심 시각 토큰은 다음과 같습니다. 이 코드를 수정할 경우, 비주얼 검토가 필수입니다.

| 요소 | 역할/상황 | HEX 코드 | 적용 범위 (기술적 요구) |
| :--- | :--- | :--- | :--- |
| **Primary** | 배경, 기본 구조, 신뢰성 확보 | `#1A2B38` (JK Deep Blue) | 썸네일의 전체 배경 또는 주요 정보 박스의 배경. |
| **Secondary** | 손실액 강조, 위험 경고 | `#C94A1B` (Risk Amber) | '잠재적 손실액' 수치($), 문제 발생 지점(Loss Point). *폰트 크기 최대화 필수.* |
| **Tertiary** | 해결책 제시, JKstory 기능 | `#007BFF` (Security Blue) | 핵심 가치 제안(AI 리스크 예측 엔진 등) 영역의 강조색. |
| **Text/Accent** | 본문 텍스트 | `#EAEAEA` | 배경 위 대비 높은 흰색 계열의 본문 텍스트. |

### II. 자동화 모듈 구조적 검증 (The Technical Blueprint) [근거: 코다리 활동 로그]

코다리가 구현한 `generate_thumbnail(data, template_id)` 함수의 입력 데이터와 출력물의 시각적 연결 고리를 정의합니다.

1. **입력 파라미터:**
    *   `[Title]` (메인 헤드라인): 폰트 크기/가중치 매핑 (`H1-Large`, Bold).
    *   `[Loss_Value]` (핵심 손실액): *반드시 Secondary Color(`#C94A1B`)로 처리.* (위치 좌표: [X, Y], Size: 5em+)
    *   `[Solution_Features]` (해결책 요소): 최소 3개. Primary Blue(`Tertiary`)의 아이콘 + 짧은 설명.

2. **출력물 레이아웃 규칙 (Hard Constraint):**
    *   **A. 배경 구조:** 전체 화면에 물류 시스템 다이어그램(흐릿한 오버레이)을 유지합니다. [근거: Self-RAG, Layout Tip]
    *   **B. 위계적 배치:** 시선 흐름은 **[문제 인식 (Loss)] $\to$ [공포감 극대화 (Risk Amber)] $\to$ [해결책 제시 (Security Blue)]**의 순서여야 합니다.
    *   **C. 폰트 스타일:** 모든 수치와 제목은 모노스페이스 또는 직관적인 산세리프체(`Roboto Mono` 등)를 사용하여 **데이터 기반의 전문성**을 강조합니다. [근거: Self-RAG, Global Style]

### III. 최종 검증 및 SOP (Standard Operating Procedure)

| 단계 | 작업 내용 | 담당 에이전트/시스템 | 필수 체크리스트 (Pass/Fail) |
| :--- | :--- | :--- | :--- |
| **1. 데이터 수집** | 컨설팅 자료에서 `Potential Loss` 값을 추출한다. | Writer / User | 📌 손실액에 대한 명확한 근거(문서, 날짜 등)가 존재하는가? |
| **2. 시각화 전처리** | `Loss_Value`를 텍스트로 변환하고, 크기 및 색상 코드를 매핑한다. | Writer / System | ✅ 손실액이 Secondary Color(`#C94A1B`)로 할당되었는가? (Fail 시 재검토) |
| **3. 자동 생성 실행** | `generate_thumbnail()` 모듈을 실행하고, 템플릿 ID와 데이터를 전달한다. | Codari / System | ✅ 최종 이미지가 V3.0의 전체 레이아웃(다이어그램 배경 + Primary/Secondary/Tertiary 구분선)을 준수하는가? |
| **4. 인간 검증 (Final Review)** | 완성된 썸네일을 확인하며, CTA와 후킹 요소가 명확한지 최종 점검한다. | Designer | ✨ *[최종 확인]* '문제 제기' $\to$ 'JKstory의 역할 제시' 흐름이 자연스러운가? |

## 🎼 JKstory X AI 음악 제작: 컴포지션 청사진 (Composition Blueprint) v1.0

**목표:** 감정적 아크(Emotional Arc)에 기반하여, 각 파트별 BGM의 BPM, 키, 장르를 명확히 지정하고, 전개되는 사운드 스케이프를 정의한다.

### Ⅰ. 핵심 분석 및 매핑 (Mapping Emotional Data)

| 스토리 단계 | 감정적 목표 (Emotion Goal) | 음악적 역할 (Musical Role) | 제안하는 청각적 질감 (Sound Texture/Mood) |
| :--- | :--- | :--- | :--- |
| **도입부** *(문제 제기)* | 위기감, 궁금증, 긴장 고조 | **Suspense Building** (긴장 조성). 낮은 주파수의 불안정성. | 앰비언트(Ambient) + 미스터리 사운드 이펙트(SFX). 드론 베이스 활용. [근거: 루나 개인 메모리] |
| **전개부 A** *(분석/진단)* | 집중, 논리적 사고, 몰입 | **Rhythmic Momentum**. 반복적인 패턴과 리듬을 통해 정보 처리 과정을 시각화. | Lo-Fi Chillhop 또는 Cinematic Electronica. 규칙적인 BPM 유지. [근거: 루나 개인 메모리] |
| **전개부 B** *(해결책 제시)* | 안정감, 신뢰, 희망, 명료함 | **Resolution & Uplift**. 화성학적으로 해결되는 느낌(Tonic resolution). 멜로디의 고조. | 시네마틱 오케스트라 또는 따뜻한 어쿠스틱 사운드. 메이저 키 사용. [근거: 루나 개인 메모리] |
| **아웃트로** *(결론/CTA)* | 여운, 확신, 마무리 | **Fade Out / Sustained Chord**. 잔향을 남기며 여운을 주는 단순한 코드 진행으로 마무리. | 미니멀(Minimal) 앰비언트 또는 피아노 솔로. BPM 점진적 하강. |

### Ⅱ. 기술적 파라미터 정의 (Technical Specifications)

이 섹션은 AI가 실제로 사용할 수 있는 '지침'입니다.

| 항목 | 기준값 / 범위 설정 | 구체적인 지시 내용 (Prompting Tip) |
| :--- | :--- | :--- |
| **주요 장르** | Cinematic Lo-Fi Electronica | 너무 가볍거나, 너무 무겁지 않은 '전문적 배경음악' 느낌을 유지. |
| **BPM (Beats Per Minute)** | 80 - 105 BPM (변동 필수) | 도입부(Ambient: 60~70) $\to$ 전개부 A(Lo-Fi: 90) $\to$ 전개부 B(Orchestral: 110). **BPM 변화가 사운드의 핵심.** [근거: 루나 개인 메모리] |
| **Key (조성)** | C Minor $\to$ Eb Major | 전체적으로 마이너 키로 시작하여 긴장감을 조성한 후, 해결책 제시 구간에서 메이저 키(Eb Major 등)로 '밝게' 전환하는 구조를 강제한다. [근거: 루나 개인 메모리] |
| **핵심 악기 구성** | Synth Pad, Deep Bass Drone, Light Drum Beat (Hip-Hop/Lo-Fi 스타일), 간헐적 Piano Arpeggio. | 현악기와 신디사이저의 조합으로 '미래지향적이면서도 인간적인' 느낌을 강조한다. |
| **사운드 효과(SFX) 지침** | 데이터 분석 사운드, 경고음(Alert Tone), 페이지 넘기는 소리(Whoosh/Swipe). | 전문성을 높이기 위해 단순 음악 외에, UI나 데이터를 다루는 듯한 '디지털적' SFX를 반드시 각 파트마다 삽입해야 한다. [근거: 루나 개인 메모리] |

### Ⅲ. 구조화된 스크립팅 가이드 (Structural Prompting)

AI에게 단순히 "이런 분위기의 노래 만들어줘"가 아니라, **'이렇게 진행해줘'**라고 명령하는 것이 핵심입니다.

```
[Intro - Suspenseful Ambient Scene] (Duration: 0:00~0:25)
BPM: ~70. Key: C Minor. Instrumentation: Deep Drone Bass, Low Frequency Synth Pad, Minimal SFX (Distant ticking clock/alert tone). Mood: Anxiety, Curiosity.

[Verse 1 - Problem Definition] (Duration: 0:26~1:00)
BPM: 85. Key: C Minor. Instrumentation: Lo-Fi Drums enter softly, Arpeggiated Synth begins. Lyrics flow over a steady, rhythmic beat. Mood: Thoughtful, Grounded.

[Chorus - The Turning Point] (Duration: 1:01~1:30)
BPM: 105. Key: Eb Major. Instrumentation: Full Orchestral Sweep, Uplifting Synth Melody, Stronger Beat. Lyrics deliver the core hope/solution message. Mood: Resolution, Optimism.

[Bridge - Deep Analysis] (Duration: 1:31~2:00)
BPM: 90. Key: C Minor $\to$ Eb Major. Instrumentation: Tempo drops slightly. Focus on Piano and Data SFX. The sound should feel like a 'breakdown' of complex data, before the final answer is presented. Mood: Intensive, Focused.

[Outro - Conclusion] (Duration: 2:01~2:30)
BPM: Slow Fade (~60). Key: Eb Major. Instrumentation: Piano solo repeats the main theme chord progression. SFX fades out with a soft, lasting reverberation. Mood: Calm, Profound Reflection.
```

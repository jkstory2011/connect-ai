## 1️⃣ 핵심 KPI 도출 전략  
(제공된 “제작 시간” 및 “오류율” 데이터 기반)

| KPI 항목 | 정의 | 목표값 (주간) | 측정 지표 | 주기 |
|----------|------|---------------|-----------|-------|
| **제작 효율성** | 평균 영상 제작 소요시간 감소 | 20%↓ (기존 대비) | `평균_제작시간 / 주간영상수` | 주간 |
| **오류율 감소** | 제작 중 발생한 오류(렌더링 실패, 스크립트 에러 등) 비율 | 30%↓ (기존 대비) | `오류건수 / 총_제작건수` | 주간 |
| **자동화 비율** | 자동화 스크립트/파이프라인을 이용한 작업 비중 | 50%↑ | `자동화_작업수 / 총_작업수` | 월간 |
| **리드타임** | 아이디어 → 완성 영상까지 걸린 평균 일수 | 5일↓ | `완성_날짜 - 아이디어_등록_날짜` | 주간 |
| **ROI (자동화 투자수익)** | 자동화 도입 비용 대비 절감된 인건비 및 시간 | 150%+ | `절감인건비 / 자동화투자비용` | 분기 |

### 데이터 활용 방법
1. **제작 시간** → `AVG(제작시간)`에서 주간 평균 산출, 목표 20% 감소.
2. **오류율** → `총 오류 / 총 제작건수` 계산, 목표 30% 감소.
3. **자동화 비율** → `자동화 작업 건수`와 `전체 작업 수` 비교.

## 2️⃣ 디자인 시스템 통합 전략 초안  
(제작 효율성 및 오류 감소를 설계 단계에서 지원)

### 2.1 비주얼 가이드라인 확장
- **모듈화된 UI 컴포넌트**: 영상 스크립트, 썸네일, 자막 등 공통 요소를 재사용 가능한 React 컴포넌트화.
- **색상/타이포그래피 일관성**: `Design System V2.0` 기준에 맞춰 색상 팔레트 및 글꼴 가이드라인을 재정리.
- **디자인 토큰**: CSS 변수/SCSS 매핑으로 색상·폰트·스페이싱을 코드화, 자동 변환 스크립트와 연동.

### 2.2 디자인 시스템과 파이프라인 통합
| 단계 | 현재 상태 | 개선 방안 |
|------|-----------|----------|
| **아이디어 캡처** | 수작업 텍스트 + 이미지 저장 | 디자인 시스템 템플릿 기반 입력 폼 제공 |
| **스케치/시안** | 수동 파일 업로드 | 자동화된 `Figma` API 호출, 컴포넌트 라이브러리 연결 |
| **스크립트 작성** | 별도 파일 → 코드화 | 디자인 시스템에 맞춘 UI 프리셋 제공, 에디터 플러그인 |
| **렌더링** | 수동 스크립트 실행 | 파이프라인에 `Design System` 체크포인트 삽입, 자동 리그레이션 테스트 |

### 2.3 KPI와 디자인 시스템 연동
- **오류율 감소**를 위해 **디자인 검증 단계** 추가: `Design System` 규칙 위반 시 자동 경고.
- **제작 효율성**을 위해 **템플릿 재사용률** KPI 도입: `템플릿 사용 건수 / 총 제작 건수`.

## 2️⃣ 자동화 파이프라인 우선순위 재확인

1. **Thumbnail 생성 모듈** – GPU 가속 배치 처리 (우선 1순위)  
   - 리스크: GPU 비용 상승, API 호출 실패 시 롤백 필요  
2. **Subtitle 생성 모듈** – 문맥 검증 로직 (우선 2순위)  
   - 리스크: 언어 모델 비용, 오탐률 관리 필요  
3. **데이터 파이프라인** – KPI 메트릭 수집 및 Grafana 연동 (우선 3순위)  
   - 리스크: 데이터 파이프라인 오류 → KPI 왜곡 가능  

> **리스크 관리**  
> * GPU 가용성 모니터링(알람 설정) → 다운타임 최소화  
> * API 호출 시 재시도 로직 + 서킷 브레이커 적용 → 장애 복구  
> * KPI 파이프라인에 **검증 단계** 삽입 → 데이터 품질 보장

# 📚 후크·CTA 라이브러리 (Hook Library)

유튜브·인스타·블로그용 후크와 CTA를 저장·조회·관리합니다.
기본 15개 후크가 내장되어 있으며, 직접 추가해서 개인 라이브러리로 키울 수 있습니다.

## 작업 종류

| ACTION | 설명 |
|---|---|
| `list` | 전체 또는 카테고리별 목록 |
| `search` | 키워드로 후크 찾기 |
| `add` | 새 후크 추가 |
| `export` | 마크다운 파일로 내보내기 |

## 카테고리

- `youtube` — 유튜브 썸네일·인트로용
- `instagram` — 인스타 피드·릴스 후크
- `blog` — 블로그 도입부
- `universal` — 모든 플랫폼 범용

## DB 파일

`hooks_db.json` — 후크 저장소. 삭제하면 기본 후크로 초기화됩니다.

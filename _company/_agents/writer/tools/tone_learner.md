# 🎨 톤 학습기 (Tone Learner)

과거 글을 스캔해 문체·어조·어휘 패턴을 분석하고 Writer memory.md에 저장합니다.
이후 글쓰기 요청 시 에이전트가 이 프로파일을 참고해 사용자 고유 톤을 복제합니다.

## 설정 방법

| 필드 | 설명 |
|---|---|
| `SOURCE_DIR` | 분석할 과거 글 폴더 (필수) |
| `FILE_TYPES` | 분석 대상 파일 형식 (기본 .md,.txt) |
| `MAX_FILES` | 최대 파일 수 (기본 20) |

## 사용 흐름

1. `SOURCE_DIR`에 본인 글 폴더 입력 → 실행
2. `memory.md`에 톤 프로파일 자동 저장
3. Writer 에이전트가 다음 글쓰기부터 해당 톤 적용

## 분석 항목

- 문체 (격식/반격식/구어)
- 평균 문장 길이
- 이모지 사용 빈도
- 자주 쓰는 어휘 Top 10
- 샘플 문장 3개

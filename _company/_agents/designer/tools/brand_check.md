# 🎨 브랜드 일관성 검사 (Brand Check)

자산 폴더의 이미지에서 색상 팔레트를 추출하고 브랜드 가이드라인 색상과 비교합니다.
브랜드 아이덴티티 일관성을 유지하는 데 활용합니다.

## 설정 방법

| 필드 | 설명 |
|---|---|
| `ASSETS_DIR` | 검사할 이미지 폴더 |
| `BRAND_COLORS` | 브랜드 색상 (hex, 예: #FF4444,#FFFFFF) |
| `COLOR_TOLERANCE` | 색상 허용 오차 (기본 25) |

## 출력

`brand_check_report.md` — 파일별 색상 일치 여부 + 전체 요약

## 필요 패키지

```bash
pip install Pillow
```

## 사용 팁

- `BRAND_COLORS`를 비우면 색상 추출만 수행 → 팔레트 파악에 유용
- 허용 오차 25가 기본값, 더 엄격하게 보려면 10~15로 낮추세요

# 💬 댓글·DM 분류기 (DM Responder)

최근 게시물의 댓글을 가져와 긍정/부정/질문/스팸으로 분류하고
답글 초안을 자동으로 생성합니다.

## 작업 종류

| ACTION | 설명 |
|---|---|
| `list_comments` | 댓글 조회 + 자동 분류 |
| `draft_replies` | 댓글 분류 + 답글 초안 생성 |

## 분류 기준

- 💚 **긍정**: "좋아요", "최고", "감사", ❤️ 등
- 🔴 **부정**: "별로", "실망", "아쉽" 등
- ❓ **질문**: "?", "어떻게", "언제" 등
- 🚫 **스팸**: "맞팔", "f4f", 외부 링크 등

## 출력

`comments_report.md` — 댓글 분류 + 답글 초안 보고서

## 필요 패키지

```bash
pip install requests
```

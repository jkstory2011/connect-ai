# 🧭 라우터 (Router)

사용자 명령을 분석해 가장 적합한 specialist 에이전트를 추천합니다.
키워드 기반 분류 + 작업 브리프 자동 생성으로 CEO의 오케스트레이션을 지원합니다.

## 작동 원리

1. `QUERY`에 사용자 명령 입력
2. 키워드 매칭으로 각 에이전트 점수 계산
3. 1순위 담당 에이전트 + 협력 에이전트 추천
4. `MODE=brief` 시 작업 지시 초안까지 생성

## 분류 기준

| 키워드 예시 | → 에이전트 |
|---|---|
| 유튜브, 채널, 조회수, 썸네일 | 📺 레오 (YouTube) |
| 인스타, 릴스, 해시태그 | 📷 Instagram |
| 코드, 개발, 버그, 자동화 | 💻 코다리 (Developer) |
| 음악, BGM, 사운드 | 🎵 루나 (Editor) |
| 글, 카피, 스크립트 | ✍️ Writer |
| 리서치, 검색, 트렌드 조사 | 🔍 Researcher |
| 수익, 매출, 전략 | 💼 현빈 (Business) |
| 일정, 캘린더, 알림 | 📱 영숙 (Secretary) |

## 출력

`routing_result.md` — 라우팅 결과 + 작업 브리프
